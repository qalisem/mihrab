# Mihrab

A daily puzzle: point toward the Kaaba from five cities. Scored by degrees off. New cities every day at local midnight, no repeats until all 166 cities are used, then a fresh shuffle.

- `index.html` the game
- `cities.js` city pool
- `daily.js` date to puzzle schedule (`LAUNCH` = puzzle No. 1)

Static site, no build step. Hosted on GitHub Pages.
